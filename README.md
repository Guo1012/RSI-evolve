# RSI-evolve · 面向大语言模型递归自训练的奖励机制遗传优化

外层遗传算法搜索奖励函数。每个候选奖励决定内层模型从自己生成的回答中选取哪些样本进行 LoRA 监督微调。外层依据训练后模型在独立任务上的表现给奖励函数打分。每次评价都从同一个基础模型 `π₀` 开始，只有同一次内层训练的相邻轮次继承适配器参数。

## 1. 奖励函数如何给回答打分

一个个体 `g = (M, w, G, φ)` 记录启用的评分模块、模块权重、门控规则和分数变换。对同一提示的 K 个回答，先计算各模块的原始分，再逐个回答合成奖励。

```text
Reward(g, 同一提示的 K 个回答):
    P ← 计算每个回答的正确性、格式、重复程度等原始模块分
    R ← 长度为 K 的零向量
    对每个启用的模块 i ∈ M:
        active ← 对所有指向 i 的门控规则，逐回答检查源模块原始分是否达到阈值
        R ← R + active × w[i] × φ[i](P[i])
    返回 R
```

同一模块的多个门控条件须同时满足。没有门控条件时，该模块对所有回答生效。例如，基因组可以始终计入正确性分，但只在正确性达到阈值时才计入长度分。可选变换包括恒等、组内排名、截断后重标度的组内标准分和二值化。实现见 [genome.py](genome.py) 和 [primitives.py](primitives.py)。

## 2. 内层：在一个候选奖励下训练和评分

```text
Train(g, 保真度 f, 种子 s):
    π ← π₀，初始化新的 LoRA 适配器
    按 f 确定训练轮数和每轮提示数
    对每一轮 t:
        X ← 按 (s, t) 从 D_train 取提示，同配置下各候选共用相同提示
        Y ← 用当前 π 为 X 中每题采样 K 个回答（首轮复用同种子的 π₀ 样本）
        对每题调用 Reward(g, 该题的回答)，保留得分最高的回答
        按每题最高分排序，保留前 keep_frac 比例的题目及其入选回答
        π ← 在这些样本上继续训练当前 LoRA 适配器
    返回 π

Fitness(g, f, 种子集 S):
    对每个 s ∈ S:
        π ← Train(g, f, s)
        在 D_fit 上用固定检查器评价 π 的输出
        J ← (指令约束全部满足的题目比例 + 数学答对率) / 2
        H ← (过长输出率 + mean(min(1, 2 × 四元词组重复率)) + 未正常结束率) / 3
        F[s] ← J − λ_h × H − λ_c × 模块数(g)
    计入本次评价的标准化训练轮数，包括命中缓存的评价
    返回 mean(F) − β × std(F)
```

默认高保真评价使用 2 个种子，每个种子训练 2 轮，每轮取 384 道题。低保真评价使用其中的第一个种子，训练 1 轮，取 192 道题。两种设置均为每题生成 4 个回答，保留半数题目。实现见 [inner.py](inner.py)，默认值见 [run.py](run.py)。

## 3. 外层：在预算内进化奖励函数

```text
Search(种群大小 N, 精英数 E, 最大代数 G_max, 搜索预算 B):
    Pop ← 以人工设计的奖励和随机合法奖励初始化 N 个个体
    对 Pop 中每个个体执行高保真 Fitness，计入初始化预算
    Archive ← 按描述符分格，每格存入高保真适应度最高的个体
    Seen ← 初始个体的基因组键和首轮训练样本选择签名

    最多迭代 G_max 代:
        Children ← 空列表
        最多尝试 10 × N 次，收集至多 N − E 个子代:
            a ← 从 Pop 中按高保真适应度进行锦标赛选择
            以概率 p_c 将 a 与另一名锦标赛选出的亲本按模块交叉，否则复制 a
            对得到的子代扰动权重和门控阈值，并以概率 p_struct 改变结构
            修复子代，使模块数、权重和门控依赖满足约束
            过滤已见的基因组键和样本选择签名，登记新键与签名
            若通过两项去重，将子代加入 Children

        L ← 在剩余预算内对子代执行低保真 Fitness
        若 L 为空，结束搜索
        按低保真得分排序，取前 ceil(η × |L|) 个作为晋级候选
        H_candidates ← 在剩余预算内完成高保真复评的晋级候选
        Pop ← 从 Pop 与 H_candidates 中保留 E 个精英，再按适应度共享补足 N 个
        用 H_candidates 更新 Archive 的各格最优个体
        若剩余预算不足一次低保真评价，结束搜索

    返回 Archive 中高保真适应度最高的至多 K_sel 个体，同分优先模块较少者
```

样本选择签名记录奖励在同一批首轮低保真样本上选中的题目和回答编号。两个表达式即使权重不同，也可能选出相同的训练数据。档案按模块数和评审类模块的绝对权重占比分格。默认种群为 6，保留 2 个精英，最多搜索 4 代，搜索预算为 64 个标准化训练轮。实现见 [search.py](search.py)。

## 4. 终选、测试与审计

```text
等待所有比较方法完成搜索，冻结各自的入围名单
对每种方法:
    对每个入围奖励 g:
        用独立的终选种子逐个调用 Train(g, 高保真, s)
        保存适配器，并在 D_sel 上计算各模型的任务分 J
    g* ← 平均 J 最高的奖励，同分优先模块较少者
    冻结 g* 及其各终选种子对应的适配器

在 D_test 上评价 π₀ 和各方法的冻结模型，报告 IFEval 和留出的 GSM8K 测试子集成绩
在 D_audit 上，分别从 π₀ 和各方法第一个终选种子的模型采样
用该方法的同一 g* 给两组回答评分，比较奖励变化、任务得分变化和高奖励回答的错误率
```

`D_train` 用于内层训练，`D_fit` 用于遗传搜索，`D_sel` 用于搜索结束后的终选。`D_test` 和 `D_audit` 仅在各方法的奖励及适配器确定后用于报告。数据划分见 [data.py](data.py)，终选与审计见 [final.py](final.py)。
